# 前端设计（Cloudflare 控制台风格，单文件）

## 主张

一句话主张：像 Cloudflare 控制台一样 плотный、可扫、敢点——首屏只做一件事，危险操作远离首屏。

记忆点：左侧深色批量条改为顶部任务进度头 `sticky`，失败清单一键下载。

## 令牌差异（相对默认）

- 浅色主蓝 `#0051c3`，深色提亮 `#6ea8ff`；品牌橙 `#f6821f` 仅 Logo 与标识，占比 ≤5%。
- 圆角 4/6/8/12，阴影 3 级，间距只用 4/8/12/16/24/32/48。
- 动效 120/200/280ms + `cubic-bezier(.2,0,0,1)`，只过渡 transform/opacity/width；跟随 `prefers-reduced-motion`。

## 布局

`Topbar56 + Sidebar（240/Rail56/<768 抽屉）+ main max1440`。文档级滚动，内层滚动仅限弹窗体与日志框。

- 悬停展开用覆盖不推挤内容；进/出意图延迟 120/220ms；键盘 Tab 聚焦亦 peek；触屏有点开按钮。
- 表格末列粘性常驻 + 不透明 + 滚动阴影；<640px 容器内横滑，页面级无横滚。
- 表单单列 max720；≥7 项分组；保存按钮不置灰，提交校验 + 首错聚焦。

## 页型

1. 概览：Stat + 清单快捷入口。
2. 浏览：单上下文栏 + 表格卡（搜/筛/排/页），双击填入操作页。
3. 操作：按模式动态字段，高级速度收折叠，`dry_run` 默认开，删域名输 `DELETE`。
4. 任务：进度头 sticky + verdict + 日志框 + 结果分页 + 失败清单下载；历史/审计走弹窗。

## 验收

- 390/768/1440 + 300 极端：`scrollWidth<=innerWidth`，浮层 `min(期望,100vw-16)`。
- 按钮必带图标；无 `div onClick`；焦点可见；正文对比 4.5:1。
