    导入记录（JSON，先预检后写入）

    上限 200 条、1MB；文件内重复或任一非法即整批拒绝、零写入。

    编辑器中可填入操作页旧内容与类型。代理开时 TTL 锁定为自动。

    批量操作

    更新与删除互斥；删除类必须限定域名范围；dry-run 默认开。
    或上传白名单文件（每行一个域名/URL，2MB 内），上传后自动填入并记入提交。

    auto 按 IP 推断 A/AAAA；CNAME 需选类型。
    危险区：删域名不可恢复。先导出备份，再填快照目录并输入 DELETE 确认。
    支持 auto 自动判断；同名同类型幂等覆盖。

    删除名称以 * 开头的记录（如 *.example.com）。记录类型在上方“记录类型”中选择（auto 等同 ALL）；建议先 dry-run 预览，且必须限定域名范围。

    provision 复用引擎完整流程：DNS→等激活→邮箱→SSL→安全/加速；邮箱要求 zone 已 active，否则记延期待重跑。

    上传后服务端落盘，提交时按路径重跑；或预览后一键填入域名。

    高级：速度与限流（默认 eco 最稳）

    fast/turbo 易触 429，请配合失败清单重跑。
